نسخه ۳ دستیار املاک مهیار
ویژگی‌ها:
- ثبت پیگیری و تماس
- ثبت مشتری
- ثبت فایل ملک
- ثبت معامله/قرارداد
- تاریخ شروع و پایان قرارداد
- یادآوری ۶۰، ۳۰ و ۷ روز قبل
- یادآوری سالانه
- خروجی تقویم .ics برای تقویم آیفون
- پشتیبان‌گیری و بازیابی
- حالت آفلاین با Service Worker و localStorage

نکته مهم:
این نسخه اطلاعات را روی همان گوشی ذخیره می‌کند. اعلان پوش واقعی وب روی iPhone نیازمند Web Push و یک سرور است. طبق مستندات Apple، Web Push در Home Screen Web App از iOS/iPadOS 16.4 پشتیبانی می‌شود و سرور باید subscription و ارسال push را مدیریت کند.

نکته مهاجرت:
اگر روی همین iPhone قبلاً نسخه ۲ با کلید mahyar_v2 استفاده شده باشد، نسخه ۳ در اولین اجرا اطلاعات پیگیری‌ها، مشتری‌ها، فایل‌ها و معاملات را از نسخه ۲ به نسخه ۳ منتقل می‌کند.
برای قراردادهای قدیمی که تاریخ پایان نداشتند، باید تاریخ پایان و یادآور را دستی تکمیل کنی.
